# FreeMyTV + MaInfo

Інтеграція для **Android TV / Google TV**. Локальна гілка FreeMyTV:
`codex/mainfo-dashboard`. Незалежний checkout MaInfo: `integrations/MaInfo`,
основна гілка `main`: інтеграцію з `codex/freemytv-bridge` вже змерджено зі
збереженням нових змін MaInfo. Код опублікований у `Deni7/free-my-tv` та
приватному `Deni7/MaInfo` відповідно. Встановлення APK виконується окремо.
Інструкція отримання оновлень оригінального
FreeMyTV: [MAINTENANCE.md](../MAINTENANCE.md).

## Що реалізовано

- Справа від великого годинника — карта областей і районів України. Червоний і
  жовтий рівні та обраний регіон відображаються за логікою MaInfo.
- Під картою — невеликий бейдж із групою та найближчим інтервалом відключення.
- Область/регіон і черга/підчерга читаються з налаштувань **MaInfo на цьому ж ТВ**.
  Окремих налаштувань розташування у FreeMyTV не потрібно.
- MaInfo оновлює тривоги своїм наявним сервісом кожні 30 секунд. Додано фонове
  оновлення графіка приблизно кожні 5 хвилин, повтор після помилки — через хвилину.
- FreeMyTV читає знімок раз на 15 секунд, коли головний екран відкритий.
  IPC, розбір контурів і малювання bitmap виконуються поза UI-потоком.
- Дані передаються лише для читання через
  `content://ua.pp.ds7.mainfo.freemytv/snapshot`, версія контракту 1.
  MaInfo перевіряє пакет `io.freemytv` та SHA-256 сертифіката його підпису.
  Ключі API, акаунти та службові дані не передаються.
- TalkBack отримує текстовий опис карти й бейджа; нові рядки додані в усі 25 каталогів.

Віджет розташований у режимі головного екрана **з великим годинником**.
Якщо ввімкнені рекомендації TMDB, їхні картки займають цю ділянку, і віджет
не відображається. LG/webOS і Samsung/Tizen не мають Android-механізму обміну
з MaInfo; інтеграція стосується Android-версії.

## Правила бейджа

- Жовтий: у підтвердженому графіку є інтервал, який ще триває або почнеться
  до кінця сьогоднішнього дня. Показується найближчий із таких інтервалів.
- Зелений: графік на сьогодні підтверджено, інтервалів до кінця дня більше немає.
- Сірий: графіка немає, формат невідомий, дані застаріли або MaInfo недоступний.

Часовий пояс для графіка — `Europe/Kiev`, незалежно від налаштування годинника ТВ.
Враховуються календарні дати, закінчення поточного інтервалу, `24:00`, перехід
через північ і літній/зимовий час. Графік отриманий понад 10 хвилин тому або
дані джерела старші за 90 хвилин не дають зеленого статусу. На карті дані старші
за 2 хвилини позначаються як застарілі; останні активні тривоги залишаються видимими.

## Що потрібно для запуску

1. **Підписати MaInfo 2.2 оригінальним ключем MaInfo.** Готовий файл:
   `MyApps/MaInfo_2_2-unsigned.apk`. Потрібен шлях до оригінального keystore або
   можливість підписати APK у середовищі, де збирався встановлений MaInfo.
   Пароль вводиться локально, не в чаті.
   SHA-256 сертифіката APK `MyApps/MaInfo_2_1.apk`:
   `318096c5983c24d8a1a42a463312ce4a3f247b9b74a9b5da06fc8b94aaa7c586`.
   Локальний debug-ключ інший, тому debug APK не підходить для оновлення цієї версії.
   Видаляти MaInfo для обходу підпису не потрібно: це втратить його налаштування.

   Приклад команди PowerShell із локальним запитом пароля:

   ```powershell
   $env:JAVA_HOME = 'C:\Program Files\Android\Android Studio2\jbr'
   & "$env:LOCALAPPDATA\Android\Sdk\build-tools\36.0.0\apksigner.bat" sign --ks 'D:\path\mainfo.keystore' --out 'MyApps\MaInfo_2_2.apk' 'MyApps\MaInfo_2_2-unsigned.apk'
   & "$env:LOCALAPPDATA\Android\Sdk\build-tools\36.0.0\apksigner.bat" verify --print-certs 'MyApps\MaInfo_2_2.apk'
   ```

2. **Оновити backend MaInfo** файлом `backend/app/scraper.py` із підготовленого
   checkout/патча. Нова відповідь `/api/power` містить
   `schedule_available_today` і `schedule_available_tomorrow`.
   Це відрізняє підтверджену відсутність відключень від відсутнього графіка.
   Раніше також губився графік на завтра, якщо він збігався із сьогоднішнім;
   тепер обидва зберігаються.

   У каталозі backend на сервері після застосування патча:

   ```sh
   docker compose up -d --build app
   ```

   Зміни backend не розгорнуті автоматично. Потрібен доступ до сервера або
   виконання цієї операції його адміністратором. До оновлення сервера непорожні
   старі графіки працюють, але порожній список обережно показується сірим.
   Розпізнавання підтвердженої відсутності відключень консервативне: незнайомий
   текст джерела означає невідомий графік.
   Джерело відключень залишилося таким самим, як у MaInfo: Львівобленерго.

3. **Оновити два додатки на ТВ.** Потрібна IP-адреса ТВ і ввімкнене налагодження
   ADB; для бездротового сполучення Android може попросити підтвердження на ТВ.
   Після перевірки сертифіката й погодження встановлення:

   ```sh
   adb connect <TV-IP>:5555
   adb install -r MyApps/MaInfo_2_2.apk
   adb install -r FreeMyTV.apk
   ```

   Ці команди оновлюють додатки; зміна домашнього екрана виконується самим
   користувачем у налаштуваннях FreeMyTV, якщо це ще не зроблено.

4. **Відкрити MaInfo один раз після оновлення.** Збережені область, регіон та
   група мають залишитися. Перевірити, що його фоновий сервіс працює й дані
   оновлюються, потім повернутися на головний екран FreeMyTV. Карта та бейдж
   з'являться після найближчого опитування (приблизно до 15 секунд).
   Примусова зупинка MaInfo припиняє його фонові оновлення; після неї його треба
   знову відкрити. Застарілі дані не трактуються як відбій чи відсутність відключень.

## Підпис FreeMyTV

`FreeMyTV.apk` підписаний наявним `freemytv.keystore`.
Дозволений у MaInfo відбиток:
`cdd3eb156628e8a5a58e53e0882aab8a38eca265fe815919815c69eee6a25802`.
Це публічний відбиток сертифіката, не секрет. При зміні ключа FreeMyTV потрібно
оновити `mobile/app/src/main/res/values/freemytv.xml` у MaInfo та перезібрати його.

## Вихідні коди та перевірки

Зміни MaInfo доступні в незалежному checkout `integrations/MaInfo`.
Для іншого checkout на тій самій основі локально підготовлений `MaInfo-integration.patch`.
Він не публікується у відкритому форку: актуальні вихідні коди MaInfo зберігаються
у приватному `Deni7/MaInfo`, гілка `main`.

```sh
git apply --check /path/to/FreeMyTV/integrations/MaInfo-integration.patch
git apply /path/to/FreeMyTV/integrations/MaInfo-integration.patch
```

FreeMyTV: `tools/check.sh` — збірка Android, переклади, пакування webOS/Tizen,
синтаксис ES5 та перевірка викликів старих браузерів.

MaInfo (з `integrations/MaInfo/mobile`):

```powershell
.\gradlew.bat assembleRelease --offline
.\gradlew.bat testDebugUnitTest --offline -I ..\scripts\verify-redesign.init.gradle -I ..\..\..\tools\mainfo-tests\verify.init.gradle
```

Другий init script додає фактичні Java-класи FreeMyTV до тестової компіляції,
не змінюючи production-збірку MaInfo. Нові тести перевіряють обмін налаштуваннями,
розділення кешів груп, відсутність хибного зеленого статусу, часові межі та
реальне малювання контурів і кольорів на 1080p/720p.
Зображення в `previews/` створені реальним Android Canvas із синтетичними
тестовими станами, це не поточні дані тривог.

Результат повного набору Android-тестів: **171 успішний із 172**.
Єдиний збій — `OverviewDesignUiTest.alertSidebarIncreasesRenderedMapScaleForBothThreatLevels`.
Він окремо відтворений на незміненому MaInfo з тієї самої ревізії.
Нові 7 тестів інтеграції проходять. Усі 19 серверних тестів, включно з 4 новими
тестами парсера графіків, також проходять.
Перевірка на фізичному ТВ ще потрібна.
